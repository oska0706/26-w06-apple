# 🍎 사과 합 10

사과에 적힌 숫자를 드래그로 이어 합이 10의 배수가 되도록 수확하는 퍼즐 게임입니다. 제한 시간 1분 동안 사과를 모아 점수를 올리고, 최고 기록에 도전해 보세요.

## 게임 시작

저장소를 내려받거나 복제한 뒤 `index.html`을 브라우저에서 엽니다. 별도의 패키지 설치나 빌드 단계 없이 바로 실행할 수 있습니다.

```text
index.html
style.css
script.js
```

게임 화면이 처음 열리면 시작 안내가 표시되고 보드는 잠겨 있습니다. **게임 시작**을 눌러야 타이머가 움직이고 사과를 선택할 수 있습니다. 시간이 끝나면 점수가 표시되며, **다시 하기**로 새 보드에서 다시 시작할 수 있습니다.

## 규칙과 조작 방법

1. 게임을 시작하면 **8×8 보드**에 1부터 9까지의 숫자가 적힌 사과가 무작위로 배치됩니다.
2. 마우스나 터치로 사과 하나를 누른 채 드래그해 **상하좌우로 인접한 사과**를 차례대로 잇습니다. 대각선으로는 이동할 수 없습니다.
3. 선택 중에는 선택 개수와 합계가 표시됩니다. 두 개 이상의 사과를 골랐을 때 합계가 **10, 20, 30처럼 10의 배수**라면 사과를 수확할 수 있습니다.
4. 유효한 합계에서 손을 떼면 선택한 사과가 사라지고, **합계만큼 점수**를 얻습니다. 예를 들어 합계가 20이면 20점을 받습니다. 조건에 맞지 않는 선택은 점수에 반영되지 않습니다.
5. 수확한 칸이 있는 열에서는 위쪽 사과가 아래로 내려옵니다. 위쪽에 생긴 빈자리는 새 사과로 채워져 보드에 빈칸이 남지 않습니다.
6. 제한 시간은 **60초**입니다. 화면에서 현재 점수와 최고 점수, 남은 시간을 확인할 수 있습니다.

최고 점수는 현재 기기의 브라우저 `localStorage`에 저장됩니다. 점수가 최고 기록을 새로 넘으면 기록이 갱신되고 꽃가루처럼 흩날리는 컨페티 효과가 나타납니다. 브라우저의 모션 감소 설정이 켜져 있으면 컨페티 애니메이션은 생략됩니다.

## 구현 내용

외부 게임 라이브러리 없이 **Vanilla JavaScript**로 게임 규칙과 상태를 구현했습니다.

- `index.html`: 게임 정보, 8×8 보드, 시작/재시작 오버레이와 안내 문구
- `style.css`: 반응형 레이아웃, 사과 타일, 선택 상태, 사과 낙하 및 컨페티 애니메이션
- `script.js`: 무작위 보드 생성, 드래그 경로·인접 여부 검사, 합계 판정, 점수·타이머·최고 기록 관리

보드는 CSS Grid로 구성했습니다. Pointer 이벤트를 사용해 마우스와 터치 입력을 함께 처리하며, 최고 점수 저장에는 브라우저 내장 `localStorage`를 사용합니다. 화면의 숫자와 상태 메시지는 스크린 리더가 확인할 수 있도록 레이블과 라이브 영역도 제공합니다.

## 커스터마이징

게임 설정은 `script.js` 맨 위의 상수에서 바꿀 수 있습니다.

- `BOARD_SIZE`: 한 변의 칸 수 (기본값 `8`)
- `ROUND_SECONDS`: 게임 제한 시간(초) (기본값 `60`)
- `HIGH_SCORE_KEY`: 브라우저에 저장하는 최고 점수의 키

화면 색상, 타일 크기와 애니메이션은 `style.css`에서, 제목과 규칙 안내는 `index.html`과 이 문서에서 수정할 수 있습니다.
