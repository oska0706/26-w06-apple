# 🍎 사과 합 10 게임

시작 버튼을 눌러 게임을 시작하고, 사과에 표시된 숫자를 상하좌우로 이어 합계가 10의 배수가 되도록 수확하는 퍼즐 게임입니다. 수확한 자리에는 위쪽 사과가 내려오고, 최고 점수를 새로 기록하면 컨페티 축하 효과가 나타납니다. 최고 점수는 브라우저에 저장됩니다.

## 게임 소개

- 게임 시작 버튼을 누르면 8×8 보드에 숫자가 표시된 사과가 나타납니다.
- 드래그로 상하좌우에 인접한 숫자를 차례로 선택합니다.
- 두 개 이상의 숫자를 골라 합이 10의 배수가 된 상태에서 손을 떼면 사과가 수확되고, 합계만큼 점수를 얻습니다. 위쪽 사과가 아래로 떨어지고 비어 있는 맨 위 칸은 새 사과로 채워집니다.
- 제한 시간은 1분이며, 현재 점수와 최고 점수를 함께 보여줍니다.
- 최고 점수를 갱신하면 컨페티 효과로 축하합니다.

## 어떻게 만들었나요

Vanilla JavaScript로 보드 생성, 드래그 선택, 점수 계산, 타이머를 구현했습니다. 화면은 HTML과 CSS로 구성하고, 최고 점수는 `localStorage`에 저장합니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 빌드나 설치 과정은 필요하지 않습니다.

## 커스터마이징한 부분

- 격자를 8×8로 구성하고 제한 시간을 1분으로 설정했습니다.
- 합이 정확히 10일 때뿐 아니라 10의 배수가 될 때마다 점수를 얻도록 했습니다.
- 사과 아이콘, 열 단위 연쇄 낙하, 최고 점수 갱신 컨페티, 모바일 드래그 조작을 추가했습니다.

실습 절차와 추가 커스터마이징 아이디어는 [guide.md](./guide.md)를 참고하세요.
